# Emotion Detection using CNN

This project is a real-time emotion detection system built using Convolutional Neural Networks (CNN), OpenCV for face detection, and Keras/TensorFlow for emotion classification. The system takes live video input from a webcam and classifies facial expressions into predefined emotion categories.

## Features

- Real-time face detection using OpenCV
- Emotion classification using a trained CNN model (`model.h5`)
- GUI interface built with Tkinter
- Displays emotion-specific quotes or responses
- Lightweight and easy to run

## Emotions Detected

- Happy 😊  
- Sad 😔  
- Angry 😠  
- Surprised 😲  
- Neutral 😐  
- Fear 😨  
- Disgust 😒

## Technologies Used

- Python
- Keras & TensorFlow
- OpenCV
- Tkinter (for GUI)
- Haarcascade for face detection
